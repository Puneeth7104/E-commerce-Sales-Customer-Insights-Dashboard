# E-commerce Sales \& Customer Insights Dashboard

Analyses sales, customer behaviour, products and geography to find revenue drivers and business opportunities.

* **Interactive dashboard (Streamlit):** *https://e-commerce-sales-customer-insights-dashboard-7brxsqdby8afp3qg7.streamlit.app/*
* **Report (GitHub Pages):** https://puneeth7104.github.io/E-commerce-Sales-Customer-Insights-Dashboard/
* **PDF report:** [`docs/report.pdf`](docs/report.pdf)

> \*\*Data note:\*\* no real dataset was supplied, so the data is \*\*synthetic\*\*, generated by `src/generate\_data.py` with a fixed seed (reproducible). It is deliberately messy (duplicates, missing values, refunds, inconsistent category names, invalid rows) so the cleaning step is real. Numbers illustrate the method, not a real business.

## What it does

|Brief step|Where|
|-|-|
|Combine order, customer, product, location tables|`src/pipeline.py` → `clean()`|
|Clean duplicates, missing values, refunds, inconsistent categories|`src/pipeline.py` (log in `data/cleaning\_log.csv`)|
|KPIs: revenue, orders, AOV, repeat-customer rate, margin, return rate|`pipeline.kpis()`|
|Monthly trend + cohort retention|Trends / Cohorts tabs|
|Customer segmentation (RFM)|`pipeline.rfm()`, Customers tab|
|Top / bottom products, categories, high-value customers, regions|Products / Geography / Customers tabs|
|Interactive dashboard with filters + recommendations|`app.py` (sidebar filters; Recommendations tab recomputes on filters)|

## Run locally

```bash
python -m venv .venv
.venv\\Scripts\\activate          # Windows  (Mac/Linux: source .venv/bin/activate)
pip install -r requirements.txt
python src/generate\_data.py     # optional: regenerate raw data
python src/pipeline.py          # clean + write data/processed
streamlit run app.py
```

Rebuild the report: `python src/build\_report.py --app-url <your-streamlit-url> --pdf` (PDF needs `pip install playwright \&\& playwright install chromium`).

## Cleaning rules

* Duplicate orders (same `order\_id`) and duplicate order lines dropped
* 12 category spellings standardised to 7; payment / status labels normalised
* Non-positive quantities and future-dated orders removed; orphan lines removed
* Missing age → median; gender/payment → `Unknown`; missing location → `UNK`; missing discount → 0
* **Revenue counts Delivered orders only.** Returned orders are treated as refunds, Cancelled orders never complete.

## Metric definitions

* Net revenue = qty × price × (1 − discount); AOV = revenue / delivered orders
* Gross margin = (net − cost) / net
* Repeat-customer rate = customers with ≥ 2 delivered orders / customers with ≥ 1
* RFM: quartile scores on recency, frequency, monetary → Champions, Loyal, Big Spenders, New/Promising, At Risk, Lost/Hibernating
